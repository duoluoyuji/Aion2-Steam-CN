### 使用方法：
1. 完全退出 AION 2 游戏及启动器；
2. 双击运行 `一键安装.bat`；
3. 弹出声明确认后，工具自动识别并处理游戏目录；
4. 游戏内语言保持默认的 **English（英文）**，进游戏直接显示中文！
5. 如需还原，退出游戏后双击 `一键还原英文.bat` 即可恢复纯净官方原版。
