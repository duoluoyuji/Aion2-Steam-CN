# Aion2-Steam-CN (永恒之塔2 国际服一键简体中文汉化)

专为 **AION 2（永恒之塔2）国际服（Steam / PURPLE）** 打造的一键简体中文汉化与还原工具。

- **支持平台**：Steam 国际正式版 / NCSoft PURPLE 国际服
- **特点**：全自动识别游戏路径、一键安装、一键还原纯净英文，不改动游戏核心执行文件。
- **作者**：B站@吃素的佩奇
- **开源主页**：https://github.com/duoluoyuji/Aion2-Steam-CN
- **声明**：完全免费开源分享，仅供交流学习，严禁任何倒卖牟利！

---

### 📥 下载与使用

1. 在右侧 **[Releases](https://github.com/duoluoyuji/Aion2-Steam-CN/releases)** 下载最新打包的压缩包；
2. 完全退出 AION 2 游戏及启动器；
3. 将下载的压缩包**完整解压到文件夹**（切勿在压缩软件内直接打开）；
4. 双击运行 `一键安装.bat` 即可自动完成汉化；
5. 游戏内语言保持默认的 **English（英文）**，进游戏直接显示中文！
6. 如需还原，双击 `一键还原英文.bat` 即可恢复纯净官方原版。
