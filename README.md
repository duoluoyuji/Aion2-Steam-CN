# Aion2-Steam-CN（永恒之塔2 国际服一键简繁汉化）

专为 **AION 2（永恒之塔2）国际服（Steam / PURPLE）** 打造的一键简体 / 繁体中文汉化与还原工具。

- **支持平台**：Steam 国际正式版 / NCSoft PURPLE 国际服
- **入口**：日文入口（游戏内「文字语言」选 **日本語**）
- **作者**：B站@吃素的佩奇
- **开源主页**：https://github.com/duoluoyuji/Aion2-Steam-CN
- **声明**：完全免费开源分享，仅供交流学习，严禁任何倒卖牟利！

## 下载与使用

1. 在右侧 **[Releases](https://github.com/duoluoyuji/Aion2-Steam-CN/releases)** 下载最新 `v1.5.7` 压缩包；
2. 完全退出 AION 2 游戏及启动器；
3. 把压缩包**完整解压到文件夹**（不要在压缩软件里直接打开）；
4. 运行 `1-图形版-双击启动.exe`，或 `2-窗口版-安装简体中文.bat` / `2-窗口版-安装繁体中文.bat`；
5. **进入游戏后，把「文字语言」设为「日本語」，重启客户端即可显示中文**（语音保持原设置）；
6. 还原：图形版点「一键还原官方日文」，或运行 `3-窗口版-还原官方日文.bat`。

> 首次安装会自动把官方原版语言包与字体包备份到游戏根目录的 `Aion2_Japanese_Backup_Safe`，请勿删除。

## 覆盖范围与已知限制

- 覆盖 153,419 条中的 152,797 条（99.6%），日常可见界面基本全中文
- 622 条因占位符/标签与官方原文不一致，保留日文，避免数值错误
- 载体字占用 1,277 个 JIS 第 2 水准生僻字；极少数情况下玩家名/聊天里的这类生僻字可能串字，属该方案固有取舍
- 游戏大更新后，请先还原官方日文，再安装新版汉化
