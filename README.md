# Aion2-Steam-CN（永恒之塔2 国际服一键简繁汉化）

专为 **AION 2（永恒之塔2）国际服（Steam / PURPLE）** 打造的一键简体/繁体中文汉化与还原工具。

- **支持平台**：Steam 国际正式版 / NCSoft PURPLE 国际服
- **特点**：自动识别游戏路径、一键安装、一键还原官方日文，不改动游戏核心执行文件
- **作者**：B站@吃素的佩奇
- **开源主页**：https://github.com/duoluoyuji/Aion2-Steam-CN
- **声明**：完全免费开源分享，仅供交流学习，严禁任何倒卖牟利！

## v1.4.3 更新内容（2026-10-29）

1. **适配 2026-10-28 客户端更新**
   官方新增了对语言 pak 的签名校验（`.sig`），直接替换 pak 会被跳过。
   本版改用**日文入口**方案：把官方日文语言包清为 0 字节 pak 并移除 `sig/ucas/utoc`，
   客户端会改读外置的 `Aion2\Content\L10N\Text\ja-JP\L10NString.dat`。已实测生效。
2. **译文按官方日文表逐条校对**
   - 423 条数值按官方修正（成就次数等）
   - 1,174 条含功能性占位符（`{se_dmg:…}`/`{se:…}` 等）的条目按官方日文重新口语化翻译
   - 197 条补入 `{pcname}` 占位符
   - 官方新增 4 条 key 已补入
3. 安装脚本改为日文入口流程：自动备份官方日文包到 `Aion2_Japanese_Backup_Safe`，还原时可一键恢复。

## 下载与使用

1. 在右侧 **[Releases](https://github.com/duoluoyuji/Aion2-Steam-CN/releases)** 下载最新压缩包；
2. 完全退出 AION 2 游戏及启动器；
3. 把压缩包**完整解压到文件夹**（不要在压缩软件里直接打开）；
4. 双击 `2-窗口版-安装简体中文.bat`（或 `1-图形版-双击启动.exe`）完成汉化；
5. **进入游戏后，把「文字语言」设为「日本語」，重启客户端即可显示中文**（语音保持原设置）；
6. 需要还原时，双击 `3-窗口版-还原官方日文.bat`。

> 说明：10-28 之后客户端不再读取外置的英文语言表，因此本版只做日文入口；英文入口的老版本已停止维护。
